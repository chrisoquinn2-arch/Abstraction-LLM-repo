# Operations roles — local obligations
**Parent:** [operations](../README.md) · **Status:** prototype placeholder.
Operations stewardship includes infrastructure reliability, context recovery, maintainability, cost observation and test execution. [Persistent role contracts](../../executive/roles/domain-responsibilities.md) are independent of temporary human/agent holders. Coordination does not allow an operator to revise governing law.

Maintain role interpretation and evidence of work through GitHub Issues and the local [skills](../skills/README.md). Propose specialization or transfer if an ongoing role exceeds a single agent's context. Raise gaps via [Forum](../../forum/README.md).
