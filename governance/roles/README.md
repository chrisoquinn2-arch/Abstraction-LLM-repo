# Governance roles — local obligations
**Parent:** [governance](../README.md) · **Status:** proposed, no role grant or active holder created here.
Governance stewardship, amendment review, authority provenance and reconsideration have persistent responsibility independently of the current agent. See [the four-domain role contracts](../../executive/roles/domain-responsibilities.md), [Governance skills](../skills/README.md) and [review procedure](../protocols/README.md).

Maintain role descriptions, authority dependencies and unresolved cases locally. Executive assigns/coordinates holders, but a change to binding powers follows Governance approval. Role gaps can be raised through [Forum](../../forum/README.md).
