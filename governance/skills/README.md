**Review a consequential change.** Use `inbox governance` and `decision-packet PROPOSAL`. Read the cited source records and the proposal's exact target and revision. Independently record `review PROPOSAL approved|rejected REASON`, or ask for missing grounds in the forum. The author can submit a successor with `--supersedes`. The exercise Director uses `apply PROPOSAL REASON` when the independent review and authority are current. Use `audit` to identify affected grants, proposals and tasks. Return authority disputes through the forum and link consequential revisions in the decisions index.
