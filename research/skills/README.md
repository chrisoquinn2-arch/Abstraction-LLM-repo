# Research skills — planned local specialization
**Parent:** [research](../README.md) · **Status:** preliminary selection contract, NOT a scientific method adopted under Task 2.

Research skill candidates include forming questions, source/provenance assessment, designing an experiment, competing interpretations, bidirectional existing-vs-proposed capability audits, and tracking what findings establish/exclude. Do not invent empirical conclusions in a skill file.

Activation must specify authority, necessary inputs, stop cases, confidence/limitations, evidence, handoff and maintenance; skills should be split/merged when changing the reader burden or scope demands it. Use the [Forum](../../forum/README.md) for method challenges.
