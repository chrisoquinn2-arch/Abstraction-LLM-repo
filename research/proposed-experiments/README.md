# Proposed experiments
[Research](../README.md). **Status:** scaffold, no authorized substantive experiment.

An experimental proposal records problem/questions, rationale, competing hypotheses/methods, predicted discriminating observations, feasible procedure, instrument/resource needs, hazards, provenance, analysis plan, failure criteria and epistemic consequences. Separate *proposed*, *authorized*, *performed*, *analyzed*, *rejected*.

Human and agents may discuss an experiment through [Research discussions](../discussions/README.md). Executive coordinates priority and resource questions; Operations examines feasibility/cost; Governance checks authority. This README alone does not authorize running a study.
