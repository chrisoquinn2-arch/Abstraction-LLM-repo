# Research roles
[Research](../README.md) · [Institutional role contracts](../../executive/roles/domain-responsibilities.md)

**Persistent responsibility:** identify scientific questions, possible directions, evidence and alternatives, then refine interpretations and report limits. Roles outlast particular human or LLM holders. Holders and live work appear through [Executive state](../../executive/state/README.md) and linked Issues.

**Status:** responsibility direction recorded, but no new grant or staffed role is enacted here. Reinterpretation with meaningful authority changes requires review; ordinary scientific criticism remains open to any contributor.
