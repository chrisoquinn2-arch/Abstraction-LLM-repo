# Research discussions
[Research](../README.md) · [Common forum](../../forum/README.md)

Use GitHub Issues to debate questions, evidence, alternative interpretations, methods and experiments. Prefix a new issue `[research]` or use the forum template with Research as a relevant area. Substantive issues should link the corresponding topic README; discuss without making all comments scientific findings.

A human can comment in the browser without specialized tools. Wrong-domain or cross-domain discussions remain valid, and Executive routes their coordination.

Maintainer: Research role for intellectual interpretation, Executive for delivery. Dissent and minority hypotheses remain linked after decisions.
