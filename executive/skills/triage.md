# Skill: Triage a cross-domain issue
**Use when:** a new Issue, missed reply, unassigned work, or repository dropbox submission is found. **Status:** prototype.
Input: Issue URL, author/created context, affected resource, possible domains, current authority/role assignments.
1. Open the original message and source links; do not infer it from title alone.
2. Identify what the sender requests and which departments might need to contribute. Treat the sender's domain guess as revisable.
3. Name an accountable coordinator; invite relevant role holders with Issue comments and linked files. If no holder, record vacancy and escalate.
4. Ask for acknowledgment, route by responsibility, preserve alternate interpretations and check for conflicts with current work.
5. Revisit before closure. Record receipt, answers, remaining objections and final disposition; link the record back to impacted document README/decision when useful.
Output: traceable Issue chronology, responsible role(s), escalation and a discoverable next action.
Stop: uncertain authority, scientific judgment outside your role, missing permissions, no review path, or context not recoverable from shared records.
