# Executive skills

[Executive](../README.md) · [Runtime](../../operations/institution/README.md)

**Triage and dispatch.** Start with `inbox executive` and `audit`. Read each thread's original target and requested result. Use `route THREAD VERSION ROLE REASON` to send it to a role in the receiving domain. Monitor acknowledgment and escalate overdue or ownerless work. Dispatch bounded tasks with source references and an objective. Use `redispatch` to transfer or resume work after authority or role changes; the prior checkpoint survives. Keep priority rationale in an Executive priority record. When a responsibility falls between roles, file it for Governance review and record an interim owner if available.
