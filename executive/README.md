# Executive

[Root index](../README.md) · [Charter](../CHARTER.md) · [Prototype governing contract](../governance/protocols/README.md)

Executive maintains cross-domain awareness, coordinates priorities, dispatches role queues, and owns unassigned conversations. The receiving domain decides the merits within its authority. Use the [executive operating skill](skills/README.md) and the shared [forum](../forum/README.md).

When an outstanding issue has no owner, an overdue acknowledgment, or a role whose authority lapsed, find a valid recipient or record escalation. Maintain this index and send unresolved boundary disputes through the forum. Review this organization if routing load obscures open work.
