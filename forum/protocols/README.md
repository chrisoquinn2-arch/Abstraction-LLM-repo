# Common forum procedures
[Forum](../README.md) · [Executive routing](../../executive/protocols/routing.md)

**Status:** draft cross-domain interface, not a merged monolithic governance/operations protocol. The forum governs intake, attribution and references. Governance retains legal review, Operations maintains tooling, Research maintains interpretations.

Participant workflow: [post/comment](../README.md) → [Executive triage](../../executive/skills/triage.md) → domain acknowledgment → response/disposition → linked primary record. Claims of automation or guaranteed pickup require observed test logs.

**Maintainer:** Executive interface steward and all affected domain maintainers; objections may be raised using the same forum.
