# Live discussions — GitHub-native
**Parent:** [forum](../README.md) · **Status:** indexed interface, not a duplicate database.

Use [all Issues](https://github.com/chrisoquinn2-arch/Abstraction-LLM-repo/issues) as the shared conversation board. Search titles for `[forum]`, `[challenge]`, `[work]` and `[exercise]`. Reply in GitHub; link any relevant Markdown source file. An issue's comments are canonical for the discussion, including dissent and escalation.

If GitHub Issues becomes unsuitable for forum load or hierarchy, compare GitHub Discussions, GitLab, Notion and Teams/SharePoint against actual human and agent workflows before replacing the source of truth.

Maintenance: Executive reviews unresolved/ownerless threads and keeps affected directory/decision links current. This index deliberately does not replicate every Issue body.
