# Long-running file discussions
[Forum](../README.md) · [Root](../../README.md)

This area is an **optional** file-native discussion format. A human can edit a Markdown thread through GitHub's browser and submit a PR; an agent can comment or propose amendments with the same review history. For an active high-volume conversation prefer a GitHub Issue (less merge contention).

A thread file should contain: title and scope, canonical URL, current question, claims and evidence, append-only attributed contributions with links and timestamps, objections, disposition state, accountable role, next step. **Do not append a new author message by overwriting prior messages**; Git history is a recovery route but does not justify data loss.

No live threads yet. Add entries to this README when a thread is created. When an Issue is canonical, store only a pointer/summary here rather than duplicate active dialogue.

**Maintainer:** Executive for routing; relevant domain for substance. **Failure mode:** conflicting PR edits require human/agent resolution; neither takes precedence merely because it merges first.
