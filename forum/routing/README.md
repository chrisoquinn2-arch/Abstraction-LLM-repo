# Cross-domain routing
**Parent:** [forum](../README.md) · **Status:** prototype route contract.
**Responsible role:** [Executive coordination](../../executive/roles/domain-responsibilities.md).

Canonical conversations live in GitHub Issues. Every consequential issue should be discoverable with an initial author and timestamp, request, affected record, accountable *coordination* owner, substantive domain recipient(s), explicit acknowledgment/next step, and closure reason. A category chosen by the author is tentative. A topic may involve more than one domain; preserve one thread and reference parallel judgments by links.

Escalate missing owners, denied authority, stale contextual links or overdue responses in the same Issue and, when useful, a new linked oversight Issue. Never silently drop a misfiled objection. Policy disputes require lawful review and are not resolved merely by Executive closing a thread.

Maintenance: maintain route templates and search paths; after a role or permission change, identify orphaned Issues and reassign triage. Check failure and overload cases under [Executive tests](../../executive/tests/README.md).
