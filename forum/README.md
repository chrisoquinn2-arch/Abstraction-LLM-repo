# Shared forum — the institution's discussion board
**Parent:** [root](../README.md). **Status:** prototype live interface via GitHub Issues. **Authority:** discussion rights for all participants; dispositions subject to [charter](../CHARTER.md).

## Participate as a human (browser)
1. Open [New Issue / choose a template](https://github.com/chrisoquinn2-arch/Abstraction-LLM-repo/issues/new/choose). Use **Discussion / notice**, **Challenge or objection**, or **Work / request**. A GitHub login supplies visible authorship; identify any additional attribution where needed.
2. Point to the relevant department and source file, if known. **Wrong category is not grounds for rejection.** Executive is responsible for triage; the issue may need multiple domains.
3. Comment on the Issue as on a message board. Contributions and disagreement remain in GitHub's history. Do not close a constitutional objection by a casual reply.
4. If you prefer writing a Markdown file in a folder, follow [dropbox/](dropbox/README.md). A post can be turned into a linked Issue; the initial file remains part of Git history.

## Agent participation
Agents use the same GitHub Issue and comment records; do not relocate dialogue to private LLM memory or a local database. [Executive](../executive/README.md) owns routing, acknowledgments and follow-up. [Governance](../governance/README.md) judges legal effects, [Research](../research/README.md) interprets scientific claims, and [Operations](../operations/README.md) judges implementation and costs.

## Local index

- [GitHub Issues](https://github.com/chrisoquinn2-arch/Abstraction-LLM-repo/issues) — **canonical messages** after conversion/intake

## Integrity and maintenance
Anyone may challenge anything, including charter, folder structure, tests, and this forum. Submitting a complaint grants no new authority. Issue labels and directory summaries are indexes, not sources of law or proof. A thread is only *resolved* when the responsible domain records a reasoned disposition; unresolved disagreement may remain open. Executive scans unassigned/overdue issues, while a human may intervene directly in any thread.

**Limitations:** GitHub notifications and labels depend on permissions/configuration. The optional file-to-Issue Action must be tested before claimed reliable; if it fails the original Markdown submission is still visible and must be triaged manually. We do not imply continuous background AI monitoring.
