# Cross-domain forum

[Root index](../README.md) · [Executive](../executive/README.md) · [Governing contract](../governance/protocols/README.md)

The exercise ledger owns open threads, routing, acknowledgment, replies, deadlines and disposition. Give a new thread a target, intended domain, evidence references and a requested action. Any participant may challenge any component, including the charter. Use `open` to raise it, `history threads/ID` to inspect replies, and `inbox executive` to detect unassigned or overdue work. A recipient acknowledges before closing with reasons. Executive owns rerouting and unresolved coverage.

Executive maintains this interface and routes governance challenges to Governance. If delay or volume obscures an important issue, raise a distinct feedback thread that links to the affected cases.
