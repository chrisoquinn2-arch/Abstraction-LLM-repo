# Forum skills
[Forum](../README.md)

- **Contribute:** Post in a GitHub Issue, cite primary sources, distinguish observation from interpretation and request a response. No role grant is required merely to object.
- **Acknowledge:** Open the original thread, declare scope and accountable receiver, provide next step and link any separate work issue.
- **Route:** [Executive triage skill](../../executive/skills/triage.md).
- **Disposition:** Link adopted decisions/PRs or evidence; preserve dissent, don't equate closure with authority.

**Status:** prototype operating instructions, not mandatory law. Update index as skills specialize.
