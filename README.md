# Intelligence and Abstract Identities — Research Program

This repository holds the governing documents for a proposed research program on intelligent behavior under abstract, incomplete, and evolving specifications.

## Status

**Founding stage.** The [Research Program Charter](CHARTER.md) is a working draft, **not yet ratified**. The research program has not passed its outset establishment tasks or adopted subordinate operating protocols.

The charter is the current authority *proposed for approval*, not a scientific finding, research plan, protocol, or authorization to begin substantive investigations.

## Current documents

- [CHARTER.md](CHARTER.md) — founding charter (working draft).

Other resources and their conventions will be established only under the charter's approved outset mandate. Future modifications should use Git history and, when appropriate, reviewable pull requests.
